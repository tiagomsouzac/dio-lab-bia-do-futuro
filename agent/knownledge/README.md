# Base de conhecimento

## Conteúdo principal
A base de conhecimento do agente Caju está organizada em dados financeiros do usuário e informações educacionais gerais sobre produtos financeiros.

## Fontes
- `data/perfil_investidor.json`
- `data/transacoes.csv`
- `data/historico_atendimento.csv`
- `data/produtos_financeiros.json`

## Uso
Esses dados são usados para:
- contextualizar o agente na conversa;
- analisar receitas e despesas;
- acompanhar metas e reserva de emergência;
- explicar conceitos financeiros gerais.

## Regras de uso
- Nunca inventar informações;
- Usar apenas os dados disponíveis;
- Não recomendar investimentos específicos;
- Explicar limitações quando faltarem dados.
